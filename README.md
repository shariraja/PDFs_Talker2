# 📄 PDFs Talker 2.0

## 🚀 Overview

PDFs Talker 2.0 is an AI-powered document interaction system that allows users to upload multiple PDF files and have intelligent conversations with them. It extracts knowledge from documents and provides accurate, context-aware answers.

---

## 🧠 Key Features

* 📂 Multi-PDF Upload Support
* 💬 Conversational AI over documents
* 🔍 Intelligent information retrieval
* 🌐 Supports multiple documents at once
* ⚡ Fast and context-aware responses
* 🧠 Memory-based Q/A system

---

## ⚙️ Tech Stack

* Python 🐍
* NLP / LLM Integration
* Vector Embeddings
* Streamlit
* LangChain / RAG Architecture (if used)
* FAISS / Similarity Search

---

## 🔄 How It Works

1. User uploads one or more PDFs
2. System extracts and processes text
3. Text is converted into embeddings
4. AI retrieves relevant context
5. User can ask questions naturally
6. System responds using document knowledge

---

## 💡 Use Cases

* Study material assistant
* Research paper analysis
* Book summarization & Q/A
* Business document understanding
